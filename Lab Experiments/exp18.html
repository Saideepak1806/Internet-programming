AgriMart Agricultural Shopping

Internet Programming Lab | Experiment 18

Objective

Develop a simple web interface for agrimart agricultural shopping.

Farmer login/register, OTP demo, add/update/delete products, upload images, manage orders/sales/shipping. Public users manage wallet, search products, cart, address and orders.

Main Modules

  • Farmer login/register, OTP demo, add/update/delete products, upload images, manage orders/sales/shipping
  • Public users manage wallet, search products, cart, address and orders

Interactive Demonstration

Result

The page displays the required modules and accepts user input. JavaScript validates the form and displays a confirmation message.
